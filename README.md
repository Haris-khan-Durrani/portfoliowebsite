# Haris Khan Durrani — Portfolio

Personal portfolio for **Haris Khan Durrani** — Head of IT, Senior Full-Stack Developer, and Solution Architect based in Dubai, UAE.

## Tech Stack
- **Framework:** Next.js 15 (App Router), React 19, TypeScript
- **Backend APIs:** Next.js Node.js Route Handlers (`/api/contact`, `/api/telemetry`)
- **Styling:** Tailwind CSS v4 + self-hosted variable fonts (`Plus Jakarta Sans`, `Instrument Serif`, `JetBrains Mono`)
- **3D & Motion:** Three.js (studio-lit PBR `PMREMGenerator` Matrix Cube / Glass Stack / Liquid Chrome sculptures), GSAP + ScrollTrigger, Motion (React Bits & Animate UI patterns)
- **SEO:** Multi-graph Schema.org JSON-LD (`Person`, `WebSite`, `ProfilePage`, `ItemList`, `SoftwareApplication`, `BreadcrumbList`), 12 pre-rendered `/projects/[slug]` case study routes, dynamic `/opengraph-image`, `/icon`, `/sitemap.xml`, `/robots.txt`, and `/manifest.webmanifest`.

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run start
```
